# Machine Learning-Based Detection Of Privilege Escalation And Backdoor Persistence Using Host-Based Security Monitoring.

This project explores the use of machine learning for detecting privilege escalation and backdoor persistence using Windows host-based security event logs.

The project uses the TON_IoT Windows 7 Security Events dataset and compares supervised and unsupervised approaches, including Random Forest and Isolation Forest.

Technologies: Python, Pandas, NumPy, Scikit-learn, Dash, Plotly

Key areas: Windows Event Logs, HIDS, data preprocessing, feature engineering, SMOTE, anomaly detection, machine learning, security monitoring.
